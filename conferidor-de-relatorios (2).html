Conferidor de relatórios

Cadastros, conferência de pedidos e tratamento configurável de relatórios CSV.

Importação: esta versão recebe CSV separado por vírgula, ponto e vírgula ou tabulação. Para usar um arquivo Excel, salve uma cópia como CSV UTF-8. Os dados ficam nesta sessão do navegador; exporte os cadastros em JSON para guardá-los.
O programa não inventa dados: campos sem cadastro ou inconsistências são sinalizados para revisão. A substituição de transportadora altera somente o código mapeado.
